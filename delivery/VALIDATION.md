## ตรวจซอฟต์แวร์ที่เกี่ยวข้อง

ใช้ Python `/opt/anaconda3/bin/python` ของเครื่องที่มี dependency อยู่แล้ว โดยไม่ติดตั้งหรือเปลี่ยน environment โครงการ:

```text
python test_memory.py    PASS (ok, ok, ok)
python test_approach.py  PASS (ok)
Flask test client: GET /       200 HTML
Flask test client: GET /state  200 JSON
```

การตรวจ Flask ไม่เปิด `/dev` ไม่เริ่ม session และไม่เปิดกล้อง การทดสอบกฎไม่โหลดโมเดล inference ไม่ใช้ API และไม่แทนการทดสอบ end-to-end

## ขอบเขตที่ยังไม่ได้ตรวจ

ไม่ได้เปิดกล้องจริง ฟังเสียงจริง รันโมเดลในเครื่องใหม่ เรียก Gemini/TTS ภายนอกใหม่ สร้าง deployment ใหม่ หรือทดลองกับผู้พิการทางสายตา ไม่ได้ยืนยันว่าทุกรุ่นโมเดลในซอร์สยังเปิดให้บัญชีใหม่ใช้ได้ และไม่ได้ติดตั้ง dependency จากศูนย์บนเครื่องใหม่

ยังไม่ได้ตรวจสิทธิ์ภาพและโมเดลทุกชิ้นใหม่จากต้นทาง โดยเฉพาะ `emotion_6.jpg` ต้องตรวจสิทธิ์ก่อนเผยแพร่ การรับรองความปลอดภัย ความแม่นยำภาคสนาม และการเข้าถึงยังอยู่นอกหลักฐานปัจจุบัน รายงานและคู่มือระบุข้อจำกัดเหล่านี้ไว้แล้ว

## การบรรจุไฟล์

ชุดซอร์สและชุดส่งมอบรวมใช้ ZIP พร้อมทดสอบ CRC ทุก entry และตรวจรายการไฟล์ตรงกับโฟลเดอร์ต้นฉบับ `SHA256SUMS.txt` ครอบคลุมไฟล์ภายในชุดส่งมอบรวมถึง ZIP ซอร์ส โดยไม่รวมไฟล์ checksum เองและ ZIP ส่งมอบรวมเพื่อหลีกเลี่ยงการอ้างอิงวน
