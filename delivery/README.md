# HENJAI — ชุดเอกสารและไฟล์ส่งมอบ

โครงการผู้ช่วยบรรยายภาพด้วย AI ที่เข้าใจอารมณ์และบริบทสำหรับผู้พิการทางสายตา

จัดทำเอกสารวันที่ 20 ตุลาคม 2569 โดยอ้างอิงซอร์สและข้อมูลที่มีอยู่ในโครงการ ไม่ได้เรียกโมเดลคลาวด์หรือทดสอบกับผู้ใช้จริงเพิ่มเติมในรอบจัดทำเอกสาร

ผู้จัดทำ: นายกิตติพงศ์ สมสอาด, นายชินพัฒน์ ขุนเจริญ และนายเรข์ณพัศ สุวรรณปริสุทธิ์ — ทีม Rushhour, หลักสูตร CEDT ภาควิชาวิศวกรรมคอมพิวเตอร์ คณะวิศวกรรมศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย

## อ่านและแก้ไขเอกสาร

PDF ทั้งสามเล่มเปิดอ่านได้ทันที ส่วนต้นฉบับหลักคือ `latex/report.tex`, `latex/user-manual.tex` และ `latex/system-manual.tex` ใช้ `common.tex` ร่วมกัน ใช้ฟอนต์ TH SarabunPSK ของ SIPA ซึ่งแนบไว้ใน `latex/assets/` (เนื้อหา 16 pt หัวเรื่องและปก 18 pt ตัวหนา)

ติดตั้ง Tectonic แล้วคอมไพล์จากโฟลเดอร์นี้:

```sh
bash latex/build.sh
```

Tectonic อาจดาวน์โหลดแพ็กเกจ TeX และสร้าง cache ในครั้งแรก ใช้ XeLaTeX แทนได้โดยเข้าที่ `latex/` แล้วคอมไพล์แต่ละ `.tex` อย่างน้อยสามรอบ ผลลัพธ์ที่คอมไพล์ใหม่ต้องตรวจการจัดหน้าและปรับ checksum ก่อนส่งต่อ

## ข้อมูลและวิธีนับผล

- `data/manifest.json` และ `data/img/`: 25 ภาพ; ภาพเพิ่มเติม `emotion_6.jpg` ไม่มีผลในรอบทดลองเดิม
- `data/results.json`: 24 รายการ สำเร็จ 21 รายการ อีก 3 รายการเป็น 429 quota errors; เวลาเฉลี่ยรายการสำเร็จ 2.242857 วินาที
- `data/results_before.json`: 24 รายการ สำเร็จทั้งหมด; เวลาเฉลี่ย 2.841667 วินาที
- `data/score.csv`: 24 แถว ยังไม่มีคะแนนมนุษย์ ไม่ใช่คะแนนศูนย์
- ป้ายอารมณ์จากคำค้นเป็นป้ายชั่วคราว: ตรงข้อความคลาส 4/6; ปรับ `surprised → surprise` แล้วตรง 5/6 ยังใช้สรุปความแม่นยำทั่วไปไม่ได้
- `case_index.csv`: เชื่อมภาพกับสถานะการทดลอง; `credits.csv`: ผู้สร้าง แหล่งที่มา และสิทธิ์ตาม manifest
- คำนวณสรุปซ้ำได้โดยไม่เรียก API: `python3 analyze_data.py` ผลเทียบกับ `data/analysis.json`

## ขอบเขตซอร์สและการรันระบบ

ซอร์สจาก `poc/` และ `web/` คัดลอกตรงตามต้นฉบับ รวมสคริปต์ประเมิน โมเดลที่มี และเอกสารประกอบภายใน ไม่รวม `.env`, key, ประวัติ Git, virtual environment, cache, ไฟล์ตั้งค่ากล้องและ backup ส่วนตัว หรือไฟล์สไลด์/ผู้สมัครภาพที่ไม่ใช่ส่วนรันระบบ ข้อมูลประเมินอยู่แยกใน `data/` ไม่ได้รวมใน ZIP ซอร์ส

ดูขั้นตอนติดตั้งในคู่มือพัฒนา ต้นแบบ Python ใช้ `python server.py` จาก `source_files/poc/` โดยต้องตั้ง `GEMINI_API_KEY` เอง และติดตั้ง dependency ให้ครบ สายเร็วต้องมี Torch/Transformers/MediaPipe เพิ่มจากรายการ requirements เดิม เว็บต้องมี serverless API และ key ฝั่งเซิร์ฟเวอร์ การเปิด HTML อย่างเดียวไม่พอ

การทดสอบภาพด้วย `eval/run.py` เรียกบริการภายนอกและเขียนทับ `results.json` กับ `score.csv` ต้องรันในสำเนาทดลอง และคัดลอกข้อมูลจาก `data/` เข้า `poc/eval/` ของสำเนานั้นก่อน **อย่ารันเพื่อทับหลักฐานส่งมอบ**

## สิทธิ์และข้อจำกัด

คงข้อมูลเครดิตภาพตาม manifest เดิม: `by` และ `by-sa` เป็นเพียงรหัสที่ผู้พัฒนาบันทึก ต้องตรวจเวอร์ชันใบอนุญาตและเงื่อนไขการเผยแพร่จากแหล่งต้นฉบับอีกครั้ง ภาพ `emotion_6.jpg` ผู้ใช้จัดหาเอง ยังไม่ยืนยันสิทธิ์สำหรับเผยแพร่สาธารณะ ตัวอย่างรูปในรายงานใช้ภาพที่มีเครดิตและคงต้นฉบับไว้ในชุดข้อมูล ไม่ได้ทำให้สิทธิ์เดิมหมดไป

น้ำหนักโมเดลและ dependency มีเงื่อนไขสิทธิ์ของผู้ให้บริการแต่ละราย ชุดส่งมอบไม่ได้กำหนดสัญญาอนุญาตใหม่ให้ซอร์สหรือทรัพยากรบุคคลที่สาม ยังไม่มีผลรับรองความปลอดภัย การเข้าถึง หรือประสิทธิผลกับผู้ใช้เป้าหมาย ระบบยังต้องตรวจกล้อง เสียง รุ่นโมเดล และโควตาก่อนสาธิตจริง
